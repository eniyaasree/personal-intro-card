# Personal Intro Card

A simple personal intro card made with **HTML** and **CSS**.

## Live Demo
👉 [View the project](https://eniyaasree.github.io/personal-intro-card/)

## What is inside
- Round profile photo
- Name, title, and a short bio
- Links to GitHub, Email, and LinkedIn
- Smooth hover effect on the buttons and the card

## What I practiced
- HTML structure (img, headings, paragraph, links)
- CSS Flexbox (centering the card and the link buttons)
- Box model: padding, border-radius, box-shadow
- Hover effects with `transition` and `transform`

## Project files
```
personal-intro-card/

    └── image.png
```

## How to run
1. Download or clone this repo
2. Open `index.html` in your browser
